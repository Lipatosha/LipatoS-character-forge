# LipatoS — Character Forge

Оптимизированный мастер создания и развития персонажа для **Foundry VTT 14** и **D&D 5e 6.0.5**.

## Главное

В версии **1.1.0 визуальный интерфейс не упрощается**: сохранены кинематографичные экраны, анимации, частицы, переходы, шрифты, звуки и расположение элементов.

Оптимизация выполняется во внутренней логике и работе с данными.

## Источник данных

Character Forge использует только установленный модуль **Laaru** (`laaru-dnd5-hw`).

Forge напрямую работает с его компендиумами классов, подклассов, рас, происхождений, особенностей, заклинаний, предметов и товаров. Выбор источников в настройках для обычной работы больше не требуется.

Названия Laaru формата:

`Русское название / English Name`

в Character Forge отображаются как:

`Русское название`

## Установка

Manifest URL:

`https://github.com/Lipatosha/LipatoS-character-forge/releases/latest/download/module.json`

Перед включением Character Forge должен быть установлен и включён **Laaru**.

## Производительность

- один общий DataManager для создания и развития;
- индексируются только нужные компендиумы Laaru;
- повторная индексация защищена общим Promise;
- индексы типов и UUID кэшируются;
- описания не обогащаются массово при построении списков;
- исправлена утечка resize-обработчиков;
- поиск заклинаний работает по готовому индексу;
- визуальные эффекты не отключаются ради производительности.
