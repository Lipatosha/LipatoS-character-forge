# LipatoS — Character Forge

Оптимизированный мастер создания и развития персонажа для **Foundry VTT 14** и **D&D 5e 6.0.5**.

## Главное

**Визуал не упрощается и не отключается.** Сохранены кинематографичные экраны, анимации, частицы, blur, переходы, шрифты, звуки и расположение элементов.

Оптимизация выполняется во внутренней логике, жизненном цикле окна и работе с данными.

## Источник данных

Character Forge использует только установленный модуль **Laaru** (`laaru-dnd5-hw`).

Forge напрямую работает с его компендиумами классов, подклассов, видов/рас, предысторий, особенностей, заклинаний, предметов и товаров. Другие Item-компендиумы мира больше не сканируются как запасной источник.

Названия Laaru формата:

`Русское название / English Name`

в Character Forge отображаются как:

`Русское название`

## Русификация

Добавлена полноценная русская локаль `ru`. Переведены все **942 ключа интерфейса** Character Forge: создание персонажа, повышение уровня, характеристики, черты, заклинания, стартовое снаряжение, магазин, настройки и служебные сообщения интерфейса.

## Установка

Manifest URL:

`https://github.com/Lipatosha/LipatoS-character-forge/releases/latest/download/module.json`

Перед включением Character Forge должен быть установлен и включён **Laaru**.

## Производительность

### Полная изоляция CSS 1.1.4

Проведён полный аудит всех JS/CSS-файлов модуля. После удаления Actor Sheet hooks оставался ещё один глобальный источник нагрузки: `styles/originate.css` подключался через `module.json` ко всему Foundry.

В этом файле находятся тысячи правил, включая `:has()`, `backdrop-filter`, `blur()`, анимации и большое количество переходов. Теперь этот CSS **не подключается глобально вообще**.

- в `module.json` больше нет глобального `styles/originate.css`;
- CSS загружается только перед явным открытием Character Forge;
- после закрытия создания/повышения уровня CSS физически удаляется из `document.head`;
- окна настроек также сами подключают CSS только на время своей работы;
- обычный Actor Sheet больше не участвует в сопоставлении CSS-селекторов Character Forge;
- внешний вид самого Character Forge не упрощён и не изменён.


### Ленивый режим 1.1.3

При обычном открытии листа персонажа Character Forge **вообще не участвует в рендере**:

- нет `renderActorSheet`-хуков;
- нет `renderCharacterActorSheet`, `renderBaseActorSheet` и `renderActorSheetV2`-хуков;
- не проверяются предметы персонажа;
- не индексируется Laaru;
- не загружаются пользовательские шрифты Forge;
- не добавляется кнопка в сам лист персонажа.

Повышение уровня через Character Forge теперь вызывается из **контекстного меню персонажа в каталоге Actor**. Правый клик по персонажу → «Повысить уровень через Character Forge».


- лист созданного персонажа запускается сразу после закрытия Character Forge без искусственной задержки;
- при закрытии явно останавливаются фоновые видео и освобождаются их декодеры;
- тяжёлое состояние мастера освобождается сразу после закрытия;
- служебные repair/ModifyItem операции вынесены из критического пути и выполняются после первого рендера листа;
- clone commit обновляет только реально изменённые Actor/Item документы вместо полной перезаписи всех предметов;
- один общий DataManager для создания и развития;
- Laaru индексируется только после явного запуска создания или повышения уровня;
- индексируются только нужные компендиумы Laaru;
- убран старый запасной проход по всем Item-компендиумам мира;
- повторная индексация защищена общим Promise;
- индексы типов и UUID кэшируются;
- описания не обогащаются массово при построении списков;
- исправлена утечка resize-обработчиков;
- поиск заклинаний работает по готовому индексу;
- визуальные эффекты во время работы мастера не отключаются.


## Одноразовое создание персонажей игроками

У ГМа в каталоге актёров рядом с кнопкой **«Создать персонажа»** находится кнопка **+**.

- по **+** открывается список всех пользователей, кроме ГМов;
- можно отметить одного или нескольких игроков;
- после подтверждения у выбранных игроков появляется кнопка **«Создать персонажа»**;
- игроку не требуется глобальное право Foundry на создание Actor — заготовку безопасно создаёт подключённый ГМ и выдаёт игроку владельца;
- если игрок закрыл Character Forge до завершения, кнопка остаётся и открывает ту же заготовку;
- после успешного создания персонажа одноразовый допуск расходуется, а кнопка игрока исчезает;
- новый персонаж можно создать только после нового разрешения ГМа.

### Закрепление бросков характеристик

При режиме бросков игрок с одноразовым разрешением получает только один набор результатов.

После первого броска результаты сохраняются на заготовке персонажа. Если игрок закроет мастер и откроет его снова, выпавшие значения и текущее распределение восстанавливаются. Перебросить их нельзя.

Новый бросок становится доступен только после того, как ГМ выдаст новый одноразовый допуск на создание следующего персонажа.

## Дополнительная русификация

- кнопка каталога теперь называется просто **«Создать персонажа»** без английской подписи в скобках;
- сокращения характеристик: **СИЛ / ЛОВ / ТЕЛ / ИНТ / МДР / ХАР**;
- значения спасбросков вида `int, wis` отображаются русскими названиями характеристик;
- подпись **«Умения в испытаниях»** нормализована до **«Спасброски»**;
- подпись `LEVEL` заменена на **«УРОВЕНЬ»** в русской локали.


### Сетевой канал 1.1.6

Для одноразового создания персонажей игроками Character Forge использует выделенный Foundry socket namespace `module.character-forge`. Начиная с 1.1.6 в манифесте явно включён `"socket": true`, поэтому запрос игрока корректно передаётся активному ГМу, который создаёт Actor-заготовку и возвращает её игроку.

После установки или обновления до 1.1.6 рекомендуется полностью перезапустить Foundry, чтобы сервер зарегистрировал namespace модуля.


## Интерфейс выбора 1.1.7

На экранах выбора **класса, вида/расы и предыстории** панель подробностей теперь всегда открыта и не имеет кнопки сворачивания.

- подробное описание постоянно видно слева;
- название выбранного варианта и краткое описание перенесены в верхнюю часть свободной области справа от панели;
- текст автоматически смещён так, чтобы не заходить на левую панель;
- фон этих трёх экранов больше не меняется от выбранного варианта;
- используется тот же статический радиальный фон, что и на экране выбора уровня;
- изображение выбранного класса/вида/предыстории остаётся частью визуального слоя.

## Сохранение незавершённого создания

Для персонажа, создаваемого игроком по одноразовому разрешению ГМа, Character Forge сохраняет черновик прямо в Actor.

Сохраняются:

- текущий экран мастера;
- выбранный класс, вид/раса, предыстория и подкласс;
- уровень и конфигурация классов;
- характеристики;
- детали персонажа;
- blueprint выбранных предметов и особенностей;
- состояние внутренних шагов выбора;
- история навигации;
- закреплённый бросок характеристик и его распределение.

Если игрок закрывает Character Forge и снова нажимает **«Создать персонажа»**, открывается та же заготовка на том месте, где он остановился. После успешного создания черновик автоматически удаляется.

- при переключении класса/вида/предыстории больше нет вспышки большой иконки на весь экран;

## Индикатор загрузки

После нажатия **«Создать персонажа»** кнопка сразу блокируется и показывает вращающийся индикатор **«Загрузка...»**. Индикатор остаётся до тех пор, пока полноэкранное окно Character Forge реально не появится в DOM.


## Компоновка и навигация 1.1.9

На выборе класса, вида/расы и предыстории панель подробностей теперь занимает ровно **правую половину экрана**.

- подробности закреплены справа и занимают 50% рабочей области;
- название выбранного варианта и краткое описание центрируются в свободной левой половине;
- кнопка **«Подтвердить выбор»** центрируется под названием выбранного варианта;
- нижнее меню выбора не заходит под правую панель;
- кнопка **«Назад»** перенесена в верхнюю шапку;
- заголовок шапки переименован в **«Создание персонажа»** и расположен строго по центру.

### Бросок и распределение характеристик

- на экране броска шесть одинаковых квадратных ячеек;
- внутри каждой ячейки показывается только выпавшее значение;
- названия характеристик и модификаторы убраны с этого экрана;
- в распределении характеристик больше нет предварительной золотой подсветки основной характеристики класса;
- у кнопок **«Далее»** убраны декоративные точки/ромбы — остаётся только текст и стрелка.

### Подсказки ссылок и состояний

Обработчик ссылок теперь работает во всём Character Forge, включая динамические внутренние экраны.

При наведении на ссылки предметов, правил и состояний показывается описание. Это относится и к ссылкам состояний вроде **«распластывается»** в описаниях заклинаний. Клик по связанному документу открывает его поверх Character Forge.

### Стартовый магазин удалён

Стартовый магазин полностью исключён из процесса создания персонажа и убран из интерфейса настроек. Финализация персонажа больше не запускает магазин и не загружает его данные.

Экран выбора класса, вида/расы и предыстории снова разделён на две половины: **подробное описание слева**, выбор и краткая информация справа.

- панель подробностей занимает левую половину экрана;
- вертикальная полоса прокрутки подробностей находится слева;
- горизонтальная прокрутка описаний отключена;
- таблицы, ссылки и длинные названия переносятся внутри панели;
- под названием выбранного класса сначала показываются основная характеристика и кость хитов, затем краткое описание;
- кнопка подтверждения и нижняя навигация остаются в правой половине.

### Список классов

На основном экране создания показываются только 12 классов в фиксированном порядке:

**Бард, Варвар, Воин, Волшебник, Друид, Жрец, Изобретатель, Монах, Паладин, Плут, Следопыт, Чародей.**

Все остальные классы скрыты с основного выбора. Кнопка разворачивания сетки для класса удалена, а все 12 классов помещаются в одну строку без горизонтального свайпа. Обводка полосы и hover-обводка классов отключены.

### Интерактивные подсказки

Подсказку особенности можно закрепить **средней кнопкой мыши**. После закрепления:

- можно переместить мышь внутрь подсказки;
- ссылки на связанные предметы и правила становятся кликабельными;
- наведение на связанную запись показывает вложенное описание;
- клик открывает связанный документ поверх Character Forge;
- системный второй preview Foundry/D&D5e подавляется, поэтому остаётся одно окно описания.

### Характеристики

Под распределением значений добавлена отдельная панель модификаторов **СИЛ / ЛОВ / ТЕЛ / ИНТ / МДР / ХАР**. Модификаторы автоматически пересчитываются при перестановке выпавших значений.

Режим покупки характеристик также считается незавершённым, пока не потрачены все доступные очки.

### Строгая проверка шагов

Кнопка **«Далее»** недоступна, пока обязательный выбор текущего шага не завершён.

В частности:

- имя персонажа обязательно;
- мировоззрение обязательно;
- портрет обязателен на шаге выбора портрета;
- класс, вид/раса, предыстория и подкласс требуют выбора;
- распределение стандартного массива или результатов броска должно быть завершено;
- в покупке характеристик должны быть распределены все очки;
- внутренние выборы особенностей, заклинаний, снаряжения и ASI нельзя пропустить, если шаг требует конкретное количество вариантов.

У предысторий книжные суффиксы вида **(EGW)** скрываются в интерфейсе: показывается только название предыстории.
