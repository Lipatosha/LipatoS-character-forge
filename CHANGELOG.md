# История изменений

## 1.1.2

- Ускорено открытие листа сразу после завершения создания персонажа.
- Убран двойной `requestAnimationFrame` перед открытием листа.
- Финальное закрытие Character Forge выполняется без дополнительной анимационной задержки.
- Служебные Advancement repair и ModifyItem операции больше не блокируют первый показ листа и запускаются в idle-время после первого рендера.
- Полностью переписан clone commit: теперь обновляются только реально изменившиеся Actor/Item документы.
- Убрана массовая повторная запись всех заклинаний и особенностей при каждом native/ModifyItem commit.
- Для внутренних commit-операций отключён лишний рендер документов.
- Визуальный интерфейс мастера создания персонажа не упрощался.

## 1.1.1

- Полная русская локализация: 942/942 ключа интерфейса.
- Добавлен `ru.json` и русский язык зарегистрирован в манифесте.
- Исправлено медленное открытие листа сразу после создания персонажа.
- Лист D&D5e теперь открывается только после полного закрытия Character Forge.
- При закрытии принудительно останавливаются фоновые видео и освобождаются ресурсы декодирования.
- После закрытия сразу очищается тяжёлое состояние мастера.
- Удалён оставшийся fallback, который при некоторых выборах сканировал все Item-компендиумы мира.
- Поиск предметов теперь остаётся строго внутри индексированных компендиумов Laaru.
- Визуальные экраны, эффекты, анимации и переходы не изменялись.

## 1.1.0

- Возвращён полный кинематографичный визуальный слой Character Forge.
- Возвращены исходные анимации, частицы, blur и переходы.
- Переход между основными экранами снова использует исходную длительность 300 мс.
- Character Forge больше не перебирает все доступные Item-компендиумы для основных списков.
- Источник данных жёстко привязан к Laaru (`laaru-dnd5-hw`).
- Laaru добавлен как обязательная зависимость.
- Названия вида «Русское / English» показываются только по русской части.
- Убран автоматический переход в окно выбора источников данных.
- Сохранены ранее сделанные оптимизации DataManager, кэшей и resize-обработчика.
