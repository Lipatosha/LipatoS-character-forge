# История изменений

## 1.1.7

- Панель «Подробнее» на выборе класса, вида/расы и предыстории теперь всегда открыта.
- Убрана возможность свернуть панель подробностей на этих трёх шагах.
- Название выбранного варианта и краткое описание перенесены в верхнюю часть свободной области справа от панели.
- Позиционирование текста учитывает постоянную ширину левой панели и не заходит на неё.
- Фон выбора класса, вида/расы и предыстории сделан статическим.
- Для этих экранов используется тот же радиальный фон, что и на выборе уровня.
- Добавлено сохранение незавершённого создания персонажа в Actor flag.
- При закрытии мастера сохраняются текущий экран, context, blueprint, уровень, классы, внутренние выборы, навигация и состояние бросков.
- При повторном открытии игрок продолжает с того же места.
- Внутренний экран выбора (wizard overlay) также восстанавливается, если игрок закрыл мастер внутри него.
- Добавлен автосейв черновика после устойчивого рендера и принудительное сохранение перед закрытием.
- После успешного создания сохранённый черновик и временный lock бросков автоматически очищаются.

## 1.1.6

- Исправлено создание персонажа игроком по разрешению ГМа.
- В `module.json` добавлен обязательный параметр `"socket": true`.
- Foundry теперь создаёт и ретранслирует выделенный канал `module.character-forge` между игроком и ГМом.
- Исправлена причина ошибки «ГМ не ответил на запрос создания персонажа» при работающем ГМе.
- После обновления требуется полный перезапуск Foundry/мира, чтобы сервер зарегистрировал socket namespace.

## 1.1.5

- Убрана подпись «(Character Forge)» из кнопки создания персонажа: теперь «Создать персонажа».
- Для ГМа рядом с кнопкой создания добавлена кнопка **+**.
- По **+** открывается список всех пользователей, кроме ГМов, с выбором одного или нескольких игроков.
- Добавлены одноразовые разрешения на создание персонажа.
- Игрок без глобального права ACTOR_CREATE может создать персонажа после разрешения ГМа: Actor-заготовку создаёт активный ГМ и выдаёт игроку OWNER.
- После успешного создания одноразовое разрешение автоматически расходуется и кнопка у игрока исчезает.
- Если мастер закрыт до завершения, повторное открытие использует ту же Actor-заготовку.
- Для одноразового разрешения бросок характеристик выполняется только один раз.
- Результаты броска и текущее распределение сохраняются в Actor flags и восстанавливаются после закрытия/повторного открытия Character Forge.
- Новый набор кубиков доступен только после нового разрешения ГМа.
- Русифицированы сокращения характеристик: СИЛ / ЛОВ / ТЕЛ / ИНТ / МДР / ХАР.
- Исправлен вывод спасбросков: `int, wis` заменяется русскими названиями характеристик.
- «Умения в испытаниях» заменено на «Спасброски».
- В русской локали `LEVEL` заменено на «УРОВЕНЬ».
- Русская и английская локали синхронизированы: 960/960 ключей.

## 1.1.4

- Проведён полный аудит всех JavaScript и CSS-файлов Character Forge.
- Подтверждено: после 1.1.3 обычный Actor Sheet не имел ни одного render-хука Character Forge.
- Найден оставшийся глобальный тормоз: огромный `originate.css` всё ещё подключался ко всему Foundry через manifest.
- Убрано глобальное подключение `styles/originate.css` из `module.json`.
- Добавлен runtime-style manager: CSS загружается только при явном запуске Character Forge.
- После закрытия мастера создания CSS полностью удаляется из DOM.
- После закрытия мастера повышения уровня CSS полностью удаляется из DOM.
- Окна настроек/внешнего вида/правил также загружают CSS только на время своей работы.
- Визуал Character Forge не изменён: используются те же самые исходные CSS-файлы, просто только тогда, когда они реально нужны.
- В обычном листе персонажа Character Forge теперь не выполняет Actor Sheet hooks и не держит тяжёлый CSS активным.

## 1.1.3

- Добавлен настоящий ленивый режим Character Forge.
- Полностью удалены все хуки рендера листа персонажа: `renderActorSheet`, `renderCharacterActorSheet`, `renderBaseActorSheet`, `renderActorSheetV2`.
- При обычном открытии листа Character Forge больше не проверяет Actor и не сканирует его предметы.
- Убрана фоновая индексация Laaru при запуске мира.
- Убрана ранняя загрузка пользовательских шрифтов Forge.
- Laaru и визуальные ресурсы загружаются только после явного запуска Character Forge.
- Повышение уровня перенесено в контекстное меню персонажа в каталоге Actor.
- Добавлен API `game.modules.get('character-forge').api.openLevelUp(actor)` для ручного запуска повышения уровня.
- Визуал мастера создания и повышения уровня не изменён.

## 1.1.2

- Ускорено открытие листа сразу после завершения создания персонажа.
- Убран двойной `requestAnimationFrame` перед открытием листа.
- Финальное закрытие Character Forge выполняется без дополнительной анимационной задержки.
- Служебные Advancement repair и ModifyItem операции больше не блокируют первый показ листа и запускаются в idle-время после первого рендера.
- Полностью переписан clone commit: теперь обновляются только реально изменившиеся Actor/Item документы.
- Убрана массовая повторная запись всех заклинаний и особенностей при каждом native/ModifyItem commit.
- Для внутренних commit-операций отключён лишний рендер документов.
- Визуальный интерфейс мастера создания персонажа не упрощался.
